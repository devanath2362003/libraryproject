# 📚 Library Management System

A full-stack MERN-based Library Management System designed to streamline book management for users and admins. This app allows users to borrow and return books, while admins can add, edit, or delete records.

## 🚀 Tech Stack

- **Frontend**: React.js, HTML, CSS
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **State Management**: useState, useEffect, useContext

## 🎯 Features

### 👨‍💻 Admin
- Add, edit, delete books
- Track borrowed and returned books
- View all user activity

### 📖 User
- Browse books
- Borrow books
- Return books
- View borrowed history
